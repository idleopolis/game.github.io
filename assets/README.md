## Download Instructions

1. Visit the Kenney.nl asset page for each pack
2. Click "Download" (all assets are free!)
3. Extract the ZIP file
4. Copy the extracted folder to the appropriate `public/assets/[world]/` directory
5. Follow the README in each world's folder for specific setup

## Fallback Graphics
The game will work WITHOUT these assets - it generates placeholder graphics automatically. But the Kenney assets look much better!
