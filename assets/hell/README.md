# Hell/Underworld/Tartarus Assets

## Download Assets from Kenney.nl

### Primary Asset Packs (Recommended)

#### 1. Tiny Dungeon (Essential)
- **URL**: https://kenney.nl/assets/tiny-dungeon
- **Purpose**: Base dungeon tiles, walls, floors, and structures
- **Usage**: Main environment tiles for underworld/hell theme
- **Download**: Click "Download" (it's free!)
- **Extract to**: `public/assets/hell/kenney_tiny-dungeon/`

#### 2. Monochrome RPG (Characters & Entities)
- **URL**: https://kenney.nl/assets/monochrome-rpg
- **Purpose**: Character sprites, NPCs, monsters
- **Usage**: Recolor to red/orange/dark tones for hellish creatures
- **Download**: Click "Download" (it's free!)
- **Extract to**: `public/assets/hell/kenney_monochrome-rpg/`

#### 3. Pixel Platformer (Additional Elements)
- **URL**: https://kenney.nl/assets/pixel-platformer
- **Purpose**: Platformer elements, obstacles, collectibles
- **Usage**: Additional environmental elements
- **Download**: Click "Download" (it's free!)
- **Extract to**: `public/assets/hell/kenney_pixel-platformer/`

### Customization Guide

Since Kenney assets are CC0 (public domain), you can freely modify them:

#### Color Scheme for Hell Theme:
- **Primary Colors**: Deep reds (#8B0000, #DC143C), dark oranges (#FF4500, #FF6347)
- **Secondary Colors**: Dark purples (#4B0082, #6A0DAD), blacks (#000000, #1A1A1A)
- **Accent Colors**: Bright oranges (#FF8C00), fire yellows (#FFD700)
- **Background**: Very dark (#0A0A0A, #1A0A0A)

#### Recommended Modifications:
1. **Recolor sprites** to hellish palette (reds, oranges, dark tones)
2. **Add fire/lava effects** using particle systems
3. **Darken backgrounds** and add atmospheric fog
4. **Combine elements** from multiple packs
5. **Add custom overlays** for hellish atmosphere

### Recommended Files to Use

#### From Tiny Dungeon:
- Floor tiles (dark stone, cracked)
- Wall tiles (stone, brick)
- Door/gate sprites
- Torch/fire elements (if included)
- Chains, spikes, traps

#### From Monochrome RPG:
- Character sprites (recolor to demon/devil theme)
- Monster/NPC sprites (recolor to hellish creatures)
- Item sprites (souls, gems, etc.)

#### From Pixel Platformer:
- Platform tiles
- Obstacle sprites
- Collectible items

### Custom Assets Needed

You may want to create or find:
- **Fire/Lava sprites** - Animated fire, lava pools
- **Soul particles** - Floating souls, spirits
- **Hell portals** - Portal/gateway effects
- **Smoke effects** - Atmospheric smoke/fog
- **UI elements** - Hell-themed buttons, panels

### Integration Notes

1. **Spritesheets**: Use the provided spritesheets for better performance
2. **Naming**: Keep original Kenney naming for easy reference
3. **Recoloring**: Create a `recolored/` subfolder for modified assets
4. **Custom Assets**: Place custom assets in `custom/` subfolder
