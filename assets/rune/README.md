# Rune World Assets

Download the following asset packs from [Kenney's Assets](https://kenney.nl/assets):

## Required Assets

1. **Rune Assets** - Download any rune/magic themed pack
   - Look for "Input Prompts" pack which contains various icons
   - Or use "UI Pack" for button elements

2. **Particle Effects** - For magical particles
   - "Particle Pack" if available

## Asset Structure

Extract the downloaded packs and organize them as:

```
public/assets/rune/
├── runes/          # Rune sprites
│   ├── rune_ember.png
│   ├── rune_frost.png
│   ├── rune_storm.png
│   ├── rune_earth.png
│   ├── rune_shadow.png
│   ├── rune_light.png
│   ├── rune_void.png
│   └── rune_cosmic.png
├── effects/        # Particle/glow effects
└── ui/             # UI elements
```

## Fallback

If assets are not available, the game will generate placeholder graphics programmatically.
